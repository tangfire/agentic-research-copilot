# AI Engineering Interview Positioning Notes

This project note is used by demo runs to show how the runtime grounds an
answer in uploaded context instead of relying only on public search.

A strong interview narrative should say that this is an Agentic Research
Runtime experiment, not a commercial Codex replacement. Start with the runtime
mechanics, then show the agent handoff flow, retrieval routing, Qdrant
grounding, GitHub MCP evidence, citation verification, evaluation, and trace
replay.

The strongest resume angle is practical experience with LangGraph orchestration,
structured tool calls, RAG quality gates, OpenAI-compatible providers,
contextual document grounding, observable failure handling, and provider
swapping.

The demo should show planner output, hybrid retrieval over project notes and
external papers, GitHub MCP evidence when useful, report citations, evaluator
metrics, and run trace artifacts. The missing work before interviews is to save
2-3 repeatable run bundles so the story does not depend on live network or
provider credentials.
