# Architecture Tradeoff Memo

## Purpose

Use this skill when the user wants to compare libraries, frameworks, runtime choices, or architectural designs.

## Required Inputs

- Candidate options
- Decision criteria
- Team or deployment constraints

## Operating Procedure

1. Name the candidate options explicitly.
2. Convert vague preferences into evaluation criteria.
3. Compare each option on fit, complexity, migration cost, operational risk, and evidence quality.
4. Separate short-term demo value from long-term maintenance value.
5. End with a recommendation and the strongest counterargument.

## Output Contract

- Decision summary
- Comparison table
- Evidence index
- Risks and mitigations
- Follow-up validation checklist
